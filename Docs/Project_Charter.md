# Project Charter - GG Finder

**Project Name:** GG Finder   
**Version:** 1.0  
**Document Type:** Project Charter

---

## 1. Executive Summary

GG Finder is a mobile application that connects gamers based on their geographical proximity. The app enables users to discover nearby gamers, view their gaming profiles, and send squad requests to form gaming teams for multiplayer games. This project aims to solve the challenge of finding compatible gaming teammates in local areas.

---

## 2. Project Objectives

- Develop a functional mobile application for iOS and Android platforms
- Enable users to discover nearby gamers within a 5km radius
- Provide detailed gamer profiles with gaming preferences
- Facilitate squad request communications between users
- Create an intuitive and user-friendly interface
- Build a local gaming community ecosystem

---

## 3. Project Scope

### In Scope:

- User registration and authentication
- GPS-based location services
- Gamer discovery within 5km radius
- User profiles with gaming information
- Squad request functionality
- Real-time online status indicators
- Push notifications for squad requests
- Location privacy controls

### Out of Scope:

- In-app chat messaging
- Matchmaking algorithms
- Social media integration
- Payment processing
- Game statistics tracking
- Voice or video calling
- In-game party creation

## 7. Technology Stack

### Development Environment
- **IDE:** Visual Studio 2022
- **Version Control:** Git and GitHub
- **Project Management:** GitHub Projects

### Frontend
- **Framework:** React Native or .NET MAUI
- **Styling:** CSS / XAML
- **State Management:** Redux / MVVM

### Backend
- **Framework:** ASP.NET Core Web API
- **Language:** C#
- **Authentication:** JWT (JSON Web Tokens)

### Database
- **Database:** SQL Server or PostgreSQL
- **ORM:** Entity Framework Core
- **Migration:** EF Core Migrations

### Testing
- **Unit Testing:** xUnit / NUnit

### Deployment
- **Backend:** Azure / AWS / Heroku
