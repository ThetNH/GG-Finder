# GG-Finder


## Project Overview
GG Finder is a mobile application that uses GPS to connect gamers within a 5km radius. The platform provides detailed gaming profiles showing players' games, ranks, skill levels, and online availability. It bridges the gap between online matchmaking and real-world local gaming communities.

---

## Target Users
Casual gamers seeking nearby players for quick gaming sessions without long-term commitments. Competitive players looking for skilled teammates for ranked matches and tournaments. Gamers new to an area wanting to expand their local gaming network.

---

## Problem Statement
Global gaming platforms suffer from latency issues, time zone differences, and communication barriers with teammates. Matchmaking systems prioritize skill over social compatibility, leading to toxic experiences and mismatched team dynamics. Local gamers remain disconnected, missing opportunities for LAN parties and in-person gaming meetups.

---

## Main Features
Browse nearby gamers within 5km showing username, game, rank, and real-time online status. View complete profiles including main game, rank, preferred role, and win rate statistics. Send squad requests instantly and receive real-time notifications for all gaming opportunities.
